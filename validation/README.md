# Validation — HUMAN ACTION REQUIRED

No human feedback is recorded yet. This folder intentionally contains a blank, honest template rather than invented participants, quotes, or outcomes.

## Required protocol

Test the canonical `app.py` with at least five people outside the team, including at least two willing users already named in `canvas-cp1.md`. Ask each person to complete the same bounded task plus one failure case. Obtain consent before recording a name or quote; use a participant code if course policy requires it.

Ask exactly:

1. Điều gì khó hiểu hoặc khó chịu nhất?
2. Kết quả này bạn có tin không — vì sao?
3. Bạn có dùng thật không — vì sao/vì sao chưa?

Do not convert polite praise into evidence. Record observable behavior and verbatim feedback. Link every product change to a row ID, or explain why no change was made.
