# Backup plan — checklist, chưa có media thật

- [ ] Tạo screenshot thật cho empty state, grounded case, graceful failure và provider error.
- [ ] Quay video ngắn thật của GS-006 + GS-013; ghi ngày/model/run ID.
- [ ] Lưu output mẫu từ trace/result thật; không dùng mock mà không gắn nhãn.
- [ ] Kiểm tra media không lộ API key, URL có key, raw data hoặc thông tin người thử.
- [ ] Chuẩn bị terminal với app command và eval summary mở sẵn.
- [ ] Nếu API/network hỏng: nói rõ sự cố, cho xem media thật đã timestamp và trace sanitize.
- [ ] Nếu app UI hỏng: dùng README/runbook + result artifact thật, không bịa live action.
- [ ] Nếu chưa có media thật trước demo: đánh dấu blocker, không tuyên bố backup đã sẵn sàng.
